## Popis Projektu
Tento projekt predstavuje osobnú webovú prezentáciu na tému astronómie/astrofotografie
Web je vytvorený ako jednostránková prezentácia s viacerými sekciami:
- About me (základné informácie o mne)
- Education (moje dosiahnuté vzdelanie)
- Astrophotography (niečo o astrofotografií, moje začiatky, programy ktoré používam a vybavenie aké mám)
- Gallery (výber mojich fotiek, ktoré sa mi podarilo zachytiť)
- Contact (osobný kontakt - FB, IG, MAIL)

## Súbory projektu
- `index.html` - Hlavná HTML stránka
- `design.css` - Štýly stránky
- `intuitive.js` - Interaktívne prvky stránky
- `images/` - Obrázky, ktoré sú použité na stránke

## Implementované prvky
- Responzívny layout pomocou `grid`, `flex` a `media queries`
- Sticky navigácia
- Rozbaľovacie sekcie pomocou JavaScript-u
- Plynulé scrollovanie na sekcie
- Hover efekty
- Mobilné navigačné menu

## Grafický návrh
Vizuálny štýl a celkové spracovanie je inšpirované nočnou oblohou. Pozadie je tmavé doplnené hviezdami a ďalšími 3 gradientmi. Tieto doplnky vytvárajú príjemný dojem a atmosféru, takú istú, ako keď som vonku pod nočnou oblohou.
